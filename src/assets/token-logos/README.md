# Token logo assets

The `.b64` files are base64-encoded 128×128 PNGs used to create Discord application emojis. They were sourced from the [Trust Wallet assets repository](https://github.com/trustwallet/assets) and resized to 128×128 where necessary.

The source repository's scripts and documentation are MIT-licensed. Individual token names and logos remain the property of their respective projects and are used only to identify the asset selected by the user.
